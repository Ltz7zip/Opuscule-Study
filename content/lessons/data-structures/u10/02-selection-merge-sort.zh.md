## 本讲目标

学完这一讲，你能用同一组数字走完简单选择、树形选择、堆排序、归并排序与基数排序，并说明为什么堆排序的建堆是 $O(n)$、归并排序的比较次数为什么稳定在 $O(n\log n)$。

## 三行回顾

- 选择类排序每趟从剩余元素中选出最小（或最大）者，放到已定位区间的末端。
- 堆排序用完全二叉树维护“堆顶即最值”，把选择代价降到 $O(\log n)$。
- 归并排序把两个有序表合并成一个，基数排序按位分配与收集，两者都不靠两两比较决定全局次序。

## 简单选择与树形选择

**简单选择排序**第 $i$ 趟在 $A[i..n]$ 中找最小值，与 $A[i]$ 交换：

```c
void SelectSort(int A[], int n) {
    for (int i = 1; i < n; ++i) {
        int min = i;
        for (int j = i + 1; j <= n; ++j)
            if (A[j] < A[min]) min = j;
        if (min != i) { int t = A[i]; A[i] = A[min]; A[min] = t; }
    }
}
```

无论初始序列如何，比较次数都是

$$
\sum_{i=1}^{n-1}(n-i)=\frac{n(n-1)}{2}
$$

$n=8$ 时为 $8\times7/2=28$ 次；移动次数最少 0 次（已有序），最多 $3(n-1)$ 次。

**树形选择排序**把 $n$ 个元素作为叶子建一棵完全二叉树，内部结点存两个孩子中的较小者，根就是全局最小值。输出根后，把该叶子改成 $\infty$，只需沿它到根的路径重赛。建树需 $n-1$ 次比较，之后每输出一个元素需 $\lceil\log_2 n\rceil$ 次比较，总计

$$
(n-1)+(n-1)\lceil\log_2 n\rceil
$$

$n=8$ 时为 $7+7\times3=28$，与简单选择相同；$n=16$ 时为 $15+15\times4=75$，明显少于简单选择的 $120$。树形选择的缺点是需要约 $2n$ 个结点的附加空间，且存在与 $\infty$ 的无用比较。

## 堆排序

**堆**是满足 $A[i]\le A[2i]$ 且 $A[i]\le A[2i+1]$ 的完全二叉树（小根堆），大根堆不等号反向。堆排序先用**筛选**（sift-down）自底向上建大根堆，再反复把堆顶与末尾交换、缩小堆、重新筛选。

对 $49,38,65,97,76,13,27,49$ 建堆：从最后一个非叶结点 $i=4$ 开始向前筛选。97 的孩子 49 更小，不动；65 的孩子 13、27 都更小，不动；38 的孩子 97、76 中 97 更大，交换后 38 继续下沉与 49 交换；最后 49 与 97 交换，49 再与 76 交换。得到

$$
97,\ 76,\ 65,\ 49,\ 49,\ 13,\ 27,\ 38
$$

随后逐次输出：

| 轮次 | 交换 | 筛选后的堆 | 已定位 |
| --- | --- | --- | --- |
| 1 | 97 ↔ 38 | 76, 49, 65, 38, 49, 13, 27 | 97 |
| 2 | 76 ↔ 27 | 65, 49, 27, 38, 49, 13 | 76, 97 |
| 3 | 65 ↔ 13 | 49, 49, 27, 38, 13 | 65, 76, 97 |

重复到堆空，得到升序序列 $13,27,38,49,49,65,76,97$。建堆的总比较次数为

$$
\sum_{h=0}^{\lfloor\log_2 n\rfloor}\frac{n}{2^{h+1}}\cdot h=O(n)
$$

不是 $O(n\log n)$；之后 $n-1$ 次筛选各 $O(\log n)$，总计 $O(n\log n)$。堆排序原地、最坏也是 $O(n\log n)$，但不稳定。

## 归并排序与基数排序

**归并排序**把序列对半分开，递归排好两半，再合并两个有序段。合并时只比较两段的首元素，较小者先出：

| 阶段 | 序列 |
| --- | --- |
| 初始 | 49, 38, 65, 97, 76, 13, 27, 49 |
| 两两归并 | 38, 49｜65, 97｜13, 76｜27, 49 |
| 四四归并 | 38, 49, 65, 97｜13, 27, 49, 76 |
| 整体归并 | 13, 27, 38, 49, 49, 65, 76, 97 |

本例合并共比较 $1+1+1+1+2+3+7=16$ 次。递推式 $T(n)=2T(n/2)+O(n)$ 给出 $T(n)=O(n\log n)$，且最好、最坏、平均都一样；代价是需要 $O(n)$ 的辅助数组。归并排序稳定，只要合并时相等元素优先取左段。

**基数排序**按位从低位到高位分配与收集。对上面 8 个数：

| 趟 | 按哪一位 | 收集结果 |
| --- | --- | --- |
| 1 | 个位 | 13, 65, 76, 97, 27, 38, 49, 49 |
| 2 | 十位 | 13, 27, 38, 49, 49, 65, 76, 97 |

每趟把 $n$ 个元素放入 $r$ 个桶再按桶序收集，$d$ 趟的总代价为 $O(d(n+r))$。本例 $d=2$、$r=10$、$n=8$，约 $2\times(8+10)=36$ 次基本操作。基数排序不做关键字比较，但要求关键字可分解为固定位，且每一趟的分配必须稳定，否则高位排序会破坏低位已排好的次序。

## 三个常见误解

> [!MYTH] 简单选择排序的比较次数与初始序列有关。
> 与初始序列无关，恒为 $n(n-1)/2$。初始序列只影响交换次数。

> [!MYTH] 堆排序建堆需要 $O(n\log n)$。
> 自底向上建堆的总代价是 $O(n)$，因为大多数结点靠近底层、下沉距离很短；$O(n\log n)$ 来自后续的 $n-1$ 次删除堆顶。

> [!MYTH] 归并排序可以原地完成。
> 标准二路归并需要 $O(n)$ 的辅助空间存放合并结果，否则只能反复移动元素，时间复杂度会变差。

## 练习

> [!PRACTICE] 1 · 数比较
> 8 个元素做简单选择排序，共比较多少次？若初始已有序，交换几次？
>
> > [!ANSWER] 看答案
> > 比较 $8\times7/2=28$ 次；已有序时每次 `min == i`，交换 0 次。

> [!PRACTICE] 2 · 树形选择
> 16 个元素做树形选择排序，总比较次数是多少？
>
> > [!ANSWER] 看答案
> > 建树 $15$ 次，之后每个输出沿路径重赛 $\log_2 16=4$ 次，共 $15+15\times4=75$ 次。

> [!PRACTICE] 3 · 基数排序
> 对 1000 个三位十进制数做基数排序，需要几趟分配？每趟多少个桶？
>
> > [!ANSWER] 看答案
> > 三位故 $d=3$ 趟；十进制故 $r=10$ 个桶。总分配收集代价为 $O(3\times(1000+10))$。

## 严格表述

大根堆满足 $A[i]\ge A[2i]$ 与 $A[i]\ge A[2i+1]$（孩子存在时）。筛选操作把根与较大的孩子交换并继续下沉，直到满足堆序，单次代价为树高 $O(\log n)$。自底向上建堆从 $i=\lfloor n/2\rfloor$ 递减到 1 依次筛选；高度为 $h$ 的结点至多下沉 $h$ 层，故总代价为 $\sum_{h\ge0}\frac{n}{2^{h+1}}h<2n=O(n)$。堆排序随后执行 $n-1$ 次“交换堆顶与末尾 + 筛选”，总时间 $O(n\log n)$。

归并排序满足 $T(n)=2T(n/2)+\Theta(n)$，由主定理得 $T(n)=\Theta(n\log n)$，递归深度 $\Theta(\log n)$。基数排序对 $d$ 位、$r$ 个桶的关键字做 $d$ 趟稳定分配，时间 $O(d(n+r))$，空间 $O(n+r)$；其正确性依赖每一趟分配与收集保持同桶内元素的相对次序。
