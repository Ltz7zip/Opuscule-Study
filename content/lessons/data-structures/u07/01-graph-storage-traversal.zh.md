## 本讲目标

学完这一讲，你能根据顶点数 $n$ 与边数 $e$ 选存储结构，写出邻接矩阵与邻接表上的 DFS、BFS 序列，并说清复杂度里的每一项从哪来。

## 三行回顾

- 图由顶点集 $V$ 和边集 $E$ 组成，记作 $G=(V,E)$。
- 存储结构只回答两件事：顶点放哪、边怎么找。
- 遍历只回答一件事：从某个点出发，按什么次序把可达点各访问一次。

## 四种存储结构

**邻接矩阵**用 $n\times n$ 的二维数组 $A$ 表示边：$A[i][j]=1$ 表示 $(i,j)\in E$；带权图存权值，无边存 $\infty$。无向图的矩阵对称，第 $i$ 行的非零元个数就是顶点 $i$ 的度。空间代价固定为 $O(n^2)$，与边数无关。

**邻接表**给每个顶点挂一条边表，表结点只记录真实存在的边。无向图每条边出现两次，空间为 $O(n+2e)$；有向图只存出边，空间 $O(n+e)$，求入度需要另建**逆邻接表**。

| 结构 | 空间 | 找全部邻边 | 适用 |
| --- | --- | --- | --- |
| 邻接矩阵 | $O(n^2)$ | $O(n)$，扫一整行 | 稠密图、频繁判边 |
| 邻接表 | $O(n+e)$ | $O(\deg v)$ | 稀疏图、遍历 |
| 十字链表 | $O(n+e)$ | 出边、入边都方便 | 有向图 |
| 邻接多重表 | $O(n+e)$ | 每条边只存一个结点 | 无向图删边 |

**十字链表**把每条弧做成一个结点，同时挂进弧尾的出边链与弧头的入边链，于是出度和入度都不必扫全表。**邻接多重表**让无向图的一条边只对应一个结点，结点里存 `ivex`、`jvex` 两个端点和两条链指针；删除一条边只改指针，不像邻接表要删两个结点。

## DFS 与 BFS

深度优先搜索沿一条路走到底，走不通再退回上一个分叉。递归实现只需要一个访问标记数组：

```c
void DFS(Graph G, int v) {
    visited[v] = TRUE; visit(v);
    for (int w = FirstAdjVex(G, v); w >= 0; w = NextAdjVex(G, v, w))
        if (!visited[w]) DFS(G, w);
}
```

广度优先搜索用队列把当前层的邻点排队，先入队先扩展：

```c
void BFS(Graph G, int v) {
    InitQueue(&Q); visited[v] = TRUE; visit(v); EnQueue(&Q, v);
    while (!QueueEmpty(Q)) {
        DeQueue(&Q, &u);
        for (int w = FirstAdjVex(G, u); w >= 0; w = NextAdjVex(G, u, w))
            if (!visited[w]) { visited[w] = TRUE; visit(w); EnQueue(&Q, w); }
    }
}
```

| 存储 | DFS | BFS |
| --- | --- | --- |
| 邻接矩阵 | $O(n^2)$ | $O(n^2)$ |
| 邻接表 | $O(n+e)$ | $O(n+e)$ |

矩阵版对每个顶点扫一整行，共 $n$ 行，故为 $O(n^2)$；邻接表版每个边表被扫一次，无向图每条边被两个端点各扫一次，故为 $O(n+2e)=O(n+e)$。两种遍历都只保证每点访问一次，不保证序列唯一，序列取决于邻点的枚举次序。

## 在六个顶点上走一遍

取无向图，顶点 $A$ 到 $F$，边为 $AB,AC,BD,CD,CE,DF,EF$，邻接表按字母序排列：

| 顶点 | 邻接点 |
| --- | --- |
| A | B, C |
| B | A, D |
| C | A, D, E |
| D | B, C, F |
| E | C, F |
| F | D, E |

从 $A$ 出发做 DFS：$A\to B\to D\to C\to E\to F$。到达 $F$ 时邻点 $D,E$ 都已访问，逐层回退，没有新点，遍历结束。

从 $A$ 出发做 BFS：访问 $A$，把 $B,C$ 入队；弹出 $B$，把 $D$ 入队；弹出 $C$，把 $E$ 入队；弹出 $D$，把 $F$ 入队。序列为 $A,B,C,D,E,F$。

这张图 $n=6$、$e=7$。邻接表共 $6+2\times 7=20$ 个表结点，一次遍历的代价为 $O(6+7)$；邻接矩阵要占 $6\times 6=36$ 个单元，其中只有 $2\times 7=14$ 个为 1，遍历要检查 36 次。

## 三个常见误解

> [!MYTH] 邻接矩阵一定比邻接表快。
> 判边 $(u,v)$ 确实是 $O(1)$，但遍历要扫整行；稀疏图上 $O(n^2)$ 远慢于 $O(n+e)$。

> [!MYTH] DFS 序列是唯一的。
> 序列由邻点枚举次序决定。把 $A$ 的邻接表改成 C, B，DFS 就变成 $A\to C\to B\to D\to F\to E$。

> [!MYTH] 有向图的邻接表能同时快速求出度和入度。
> 邻接表只存出边，出度是 $O(\deg^+v)$，入度要扫全表 $O(e)$，所以才有逆邻接表与十字链表。

## 练习

> [!PRACTICE] 1 · 选结构
> 一张 1000 个顶点、1200 条边的无向图，邻接矩阵与邻接表各需多少存储单元（忽略指针开销）？
>
> > [!ANSWER] 看答案
> > 矩阵 $1000^2=10^6$ 个；邻接表 $1000+2\times1200=3400$ 个表结点。稀疏图选邻接表。

> [!PRACTICE] 2 · 写序列
> 上图中从 $C$ 出发，按字母序做 DFS 与 BFS。
>
> > [!ANSWER] 看答案
> > DFS：$C\to A\to B\to D\to F\to E$；BFS：$C\to A\to D\to E\to B\to F$。

> [!PRACTICE] 3 · 判连通
> 8 个顶点、6 条边的无向图，从任一顶点出发的 DFS 能访问全部顶点吗？
>
> > [!ANSWER] 看答案
> > 不能保证。8 个顶点的连通图至少需要 7 条边，6 条边必然存在孤立点或分裂成多个连通分量。

## 严格表述

设 $G=(V,E)$，$|V|=n$，$|E|=e$。DFS 的递归不变式是：调用 `DFS(v)` 时 $v$ 尚未标记，返回时 $v$ 及其所有可达的未访问顶点都已标记。每次递归标记一个新顶点，故恰好调用 $n$ 次；邻接表下每条边被检查两次，时间为 $T(n,e)=O(n+e)$。BFS 用队列实现，队列中任意时刻至多积压一层顶点，空间为 $O(n)$，正确性来自“按距源点的距离非降序出队”这一不变式。
