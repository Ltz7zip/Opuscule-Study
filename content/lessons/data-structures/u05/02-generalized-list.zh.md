## 本讲目标

学完这一讲，你能判断一个广义表是原子还是子表，能用取表头与取表尾拆解任意广义表，能算出长度与深度，能读懂 tag 与 union 组成的存储结点。

## 三行回顾

- 广义表是 $n$ 个元素的有穷序列，元素可以是原子，也可以是广义表。
- 表头是第一个元素，表尾是除表头外其余元素组成的表，表尾一定是表。
- 长度是顶层元素个数，深度是括号的最大嵌套层数。

## 表头表尾与长度深度

广义表记作 $\mathrm{LS}=(a_1,a_2,\dots,a_n)$。若 $a_i$ 不可再分，称其为原子；若 $a_i$ 本身是广义表，称其为子表。原子通常用小写字母，子表用大写字母。

两个基本操作：`GetHead` 取第一个元素，`GetTail` 取剩余部分组成的表。注意 `GetTail` 返回的永远是表，即使只剩一个元素，也会被包在一层括号里。

设 $A=()$，$B=(e)$，$C=(a,(b,c))$，$D=(A,B,C)$，逐层拆解：

| 表达式 | 表头 | 表尾 | 长度 | 深度 |
| --- | --- | --- | --- | --- |
| $A=()$ | 无定义 | 无定义 | 0 | 1 |
| $B=(e)$ | $e$ | $()$ | 1 | 1 |
| $C=(a,(b,c))$ | $a$ | $((b,c))$ | 2 | 2 |
| $D=(A,B,C)$ | $A$ | $(B,C)$ | 3 | 3 |

长度只数顶层元素：$D$ 的顶层是 $A$、$B$、$C$ 三个，所以长度为 3，不因为 $C$ 内部还有元素而增加。深度数括号层数：$D$ 一层，$C$ 再一层，$(b,c)$ 再一层，故深度为 3。空表 $A=()$ 长度为 0，但深度记作 1，因为那一对括号本身占一层。

再看 $D$ 的逐步拆解：`GetHead(D)=A`，`GetTail(D)=(B,C)`；对 `(B,C)` 再取表头得 $B$。用 `GetHead` 与 `GetTail` 可以把任意广义表完全分解，这正是它便于递归处理的原因。

## 广义表的存储结构

由于元素类型不统一（有时是原子，有时是表），结点必须自带类型标记。常见做法是 tag 加 union：

```c
typedef enum { ATOM, LIST } ElemTag;

typedef struct GLNode {
    ElemTag tag;
    union {
        char atom;            /* tag == ATOM */
        struct GLNode *hp;    /* tag == LIST，指向子表 */
    } ptr;
    struct GLNode *tp;        /* 指向同层的下一个结点 */
} GLNode, *GList;
```

`tag` 区分两种结点：原子结点的 `atom` 存字符，表结点的 `hp` 指向子表的第一个结点。`tp` 则把同一层的元素串起来。于是每个广义表都对应一条 `tp` 链，子表通过 `hp` 挂到链上。

以 $D=(A,B,C)$ 为例，顶层是一条三结点的 `tp` 链，分别对应 $A$、$B$、$C$；这三个结点都是 `LIST` 类型，各自的 `hp` 指向自己的子链。$A$ 是空表，`hp` 为 `NULL`；$C$ 的子链前一个结点是原子 `a`，后一个结点是 `LIST`，其 `hp` 再指向 `b`、`c` 组成的链。

| 结点类型 | tag | 有效字段 | 含义 |
| --- | --- | --- | --- |
| 原子 | `ATOM` | `atom` | 一个不可分元素 |
| 子表 | `LIST` | `hp` | 指向子表首结点 |
| 同层后继 | 任意 | `tp` | 指向本层下一个元素 |

> [!NOTE]
> 另一种教材写法把 `hp` 与 `tp` 都放在 union 里，表结点用 `hp/tp`，原子结点只用 `atom/tp`。两种写法语义相同，区别只在内存布局，读代码时先看 tag 的分支再判断哪个字段有效。

## 递归操作

广义表的操作几乎都是递归的，因为定义本身就是递归的。求深度是最典型的一个：

```c
int GListDepth(GList L) {
    if (!L) return 1;                     /* 空表深度为 1 */
    if (L->tag == ATOM) return 0;         /* 原子深度为 0 */
    int max = 0;
    for (GList p = L; p; p = p->tp) {
        int d = GListDepth(p->tag == ATOM ? NULL : p->ptr.hp);
        if (p->tag == ATOM) d = 0;
        if (d > max) max = d;
    }
    return max + 1;
}
```

对 $D$ 调用：顶层三个元素，$A$ 返回 1，$B$ 返回 0（原子 $e$），$C$ 的子链里 $(b,c)$ 返回 1，故 $C$ 返回 $1+1=2$。取最大值得 2，再加 1 得 3，与手算一致。

复制也是递归的：原子直接复制，子表先复制 `hp` 再复制 `tp`。求长度则不需要递归，沿 `tp` 链数到底即可，是 $O(n)$ 的迭代。区分「哪些操作该递归、哪些不该」，取决于操作是否要进入子表内部。

## 三个常见误解

> [!MYTH] 广义表就是二维数组。
> 二维数组每行长度相同、元素类型一致；广义表的子表长度任意、可以嵌套任意层，元素还可以是原子，表达能力强得多。

> [!MYTH] 表尾就是最后一个元素。
> 表尾是除表头外的所有元素组成的表。$(a,b,c)$ 的表尾是 $(b,c)$，不是 $c$；表尾一定是表，表头才可能是原子。

> [!MYTH] 深度等于最长子表的长度。
> 深度数的是嵌套层数，与元素个数无关。$(a,b,c)$ 长度为 3 而深度只有 1；$(a,(b,c))$ 长度为 2 而深度为 2。

## 练习

> [!PRACTICE] 1 · 求长度深度
> $E=((a,b),c,(d,(e)))$ 的长度与深度各是多少？
>
> > [!ANSWER] 看答案
> > 顶层三个元素，长度 3；最深到 $(e)$ 那一层，深度 3。

> [!PRACTICE] 2 · 取头取尾
> 对 $E$ 连续取表头两次，得到什么？
>
> > [!ANSWER] 看答案
> > `GetHead(E)=(a,b)`，再取表头得 $a$。若第二次对表尾操作则会得到 $(b)$。

> [!PRACTICE] 3 · 判类型
> $F=(())$ 的长度与深度是多少？
>
> > [!ANSWER] 看答案
> > 顶层只有一个元素，是空表，长度 1；括号嵌套两层，深度 2。

## 严格表述

广义表是 $n\ge 0$ 个元素的有穷序列 $\mathrm{LS}=(a_1,a_2,\dots,a_n)$，其中每个 $a_i$ 或为原子或为广义表，$n=0$ 时称为空表。表头 $\mathrm{GetHead}(\mathrm{LS})=a_1$，表尾 $\mathrm{GetTail}(\mathrm{LS})=(a_2,\dots,a_n)$，表尾恒为广义表。长度定义为顶层元素个数，深度定义为括号的最大嵌套层数，空表长度为 0、深度为 1，原子深度为 0。存储上采用带标志域的结点：原子结点以 `atom` 存放元素，表结点以 `hp` 指向子表首结点，两类结点均以 `tp` 指向同层后继，从而把嵌套结构展开为「同层链 + 子表指针」的二叉链形式。求深度与复制按定义递归实现，求长度可沿 `tp` 链迭代完成。
