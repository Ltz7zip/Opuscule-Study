## 本讲目标

学完这一讲，你能写出顺序栈的入栈出栈判满判空，能用手工追踪表判断括号串是否合法，能把中缀表达式转成后缀式并求值，并说清这类问题为什么非栈不可。

## 三行回顾

- 栈是只允许在表尾（栈顶）插入和删除的线性表，后进先出。
- 顺序栈用 `top` 指示栈顶下标，链栈用单链表头插，两者基本操作都是 $O(1)$。
- 凡是可以「推迟到遇到对应符号再处理」的问题，栈都是自然选择。

## 顺序栈与链栈

顺序栈用一个数组加一个栈顶指针：

```c
#define MAXSIZE 50
typedef struct {
    int data[MAXSIZE];
    int top;            /* 空栈 top = -1 */
} SqStack;

int push(SqStack *S, int x) {
    if (S->top == MAXSIZE - 1) return 0;   /* 满 */
    S->data[++S->top] = x;
    return 1;
}

int pop(SqStack *S, int *x) {
    if (S->top == -1) return 0;            /* 空 */
    *x = S->data[S->top--];
    return 1;
}
```

`top` 的约定要统一：写成 `top = -1` 表示空栈时，入栈是「先加后用」，出栈是「先用后减」。若改用 `top` 指向栈顶的下一个空位，所有判断和取值都要跟着改，混用两种约定是常见 bug 来源。

链栈把新结点插在头指针之后，栈顶就是首元结点。它不会溢出（除非内存耗尽），入栈出栈同样是 $O(1)$，代价是每个元素多一个指针域。

| 实现 | 判空 | 判满 | 入栈 | 出栈 |
| --- | --- | --- | --- | --- |
| 顺序栈 | `top == -1` | `top == MAXSIZE-1` | $O(1)$ | $O(1)$ |
| 链栈 | `top == NULL` | 无（受内存限制） | $O(1)$ | $O(1)$ |

## 括号匹配

给定只含 `()[]{}` 的串，判断括号是否成对且嵌套正确。规则是：遇到左括号就压栈；遇到右括号就检查栈顶是否为对应的左括号，是则弹出，否则非法；扫描结束时栈必须为空。

手工追踪 `([{}])`：

| 读入 | 动作 | 栈内容（底→顶） |
| --- | --- | --- |
| `(` | 压栈 | `(` |
| `[` | 压栈 | `( [` |
| `{` | 压栈 | `( [ {` |
| `}` | 栈顶是 `{`，弹出 | `( [` |
| `]` | 栈顶是 `[`，弹出 | `(` |
| `)` | 栈顶是 `(`，弹出 | 空 |

结束时栈空，串合法。再看 `([)]`：读到 `)` 时栈顶是 `[`，与 `(` 不匹配，立即判定非法。这说明栈检查的不只是数量，还有嵌套次序——而数量检查用几个计数器就能做，次序检查必须靠栈记住「最近一个未闭合的是谁」。

## 表达式求值与后缀式

中缀表达式 `3 + 4 * 5` 的运算符优先级藏在位置里，计算机不便直接顺序求值。后缀式（逆波兰式）把运算符写在操作数之后，`3 4 5 * +` 无需括号也无需优先级。

求值算法只用一个栈：读到数字就压栈；读到运算符就弹出两个操作数，先弹出的是右操作数，运算后把结果压回。

追踪 `3 4 5 * +`：

| 读入 | 动作 | 栈（底→顶） |
| --- | --- | --- |
| 3 | 压栈 | 3 |
| 4 | 压栈 | 3 4 |
| 5 | 压栈 | 3 4 5 |
| `*` | 弹 5、4，算 $4\times5=20$ | 3 20 |
| `+` | 弹 20、3，算 $3+20=23$ | 23 |

结果是 23，与中缀一致。若把弹出顺序写反成 $5-4$，减法与除法就会出错，这是实现时的头号陷阱。

> [!NOTE]
> 中缀转后缀也靠栈：操作数直接输出，运算符入栈前先弹出所有优先级不低于它的栈顶运算符，左括号入栈后当作最低优先级，遇到右括号就弹到左括号为止。转换与求值是同一套后进先出逻辑的两次使用。

## 三个常见误解

> [!MYTH] 栈只能在数组上实现。
> 链栈同样合法，甚至更灵活。栈约束的是「只在一端增删」这一行为，与底层是数组还是链表无关。

> [!MYTH] 括号匹配只要左右括号总数相等。
> `([)]` 的括号数量完全相等，嵌套次序却是错的。必须用栈记录最近未闭合的符号。

> [!MYTH] 后缀表达式求值时先弹出的操作数在左边。
> 先弹出的是右操作数。对加法和乘法无所谓，对减法和除法会直接算错。

## 练习

> [!PRACTICE] 1 · 判合法
> 用栈追踪 `{[()]}` 与 `{[(])}`，指出后者在第几个字符出错。
>
> > [!ANSWER] 看答案
> > 前者全程匹配、结束时栈空，合法。后者读到 `]` 时栈顶是 `(`，与 `[` 不匹配，在第 5 个字符出错。

> [!PRACTICE] 2 · 求后缀
> 求 `5 1 2 + 4 * + 3 -` 的值。
>
> > [!ANSWER] 看答案
> > $1+2=3$，$3\times4=12$，$5+12=17$，$17-3=14$，结果为 14。

> [!PRACTICE] 3 · 判空
> `top` 初值为 -1 的顺序栈，连续入栈 3 个再出栈 2 个后，`top` 是多少？栈中有几个元素？
>
> > [!ANSWER] 看答案
> > 入栈后 `top=2`，出栈两次后 `top=0`，栈中剩 1 个元素。

## 严格表述

栈是限定仅在表的一端进行插入和删除的线性表，允许操作的一端称为栈顶，另一端称为栈底，其行为遵循后进先出原则。顺序栈以数组存储元素并用栈顶下标 `top` 标识栈顶位置，约定 `top = -1` 时为空栈，入栈与出栈均为 $O(1)$；链栈以单链表实现，插入删除均在表头进行，同样为 $O(1)$ 且不受固定容量限制。括号匹配以栈保存尚未闭合的左括号，扫描中遇到右括号即与栈顶比对，扫描结束时栈必须为空；后缀表达式求值以栈保存操作数，遇运算符弹出两个操作数，先弹出者为右操作数，运算结果压回栈中。二者都依赖同一性质：后出现的待处理对象必须先被处理。
