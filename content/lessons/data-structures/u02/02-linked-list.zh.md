## 本讲目标

学完这一讲，你能写出单链表按位序插入、删除的指针操作，能说清头指针与头结点的分工，能比较单链表、双向链表、循环链表各自的代价，并能在顺序表与链表之间给出有理由的选择。

## 三行回顾

- 链表用一组任意的存储单元存放元素，结点内的指针记录后继位置。
- 按位序查找是 $O(n)$，已知前驱时插入删除是 $O(1)$。
- 头结点不存数据，能让首元结点的插入删除与其他位置完全一致。

## 结点、头指针与头结点

单链表的每个结点由数据域和指针域组成：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

`LinkList L` 指向第一个结点，这个指针叫头指针，它是链表的唯一标识；`L == NULL` 表示空表。另一种做法是额外加一个不存数据的头结点，`L->next` 才是首元结点。头结点让「在第一个位置插入」「删除第一个元素」不再需要修改头指针，代码路径和中间位置完全一致，代价是多占一个结点的空间。

存储上，结点的物理地址可以任意，逻辑次序靠 `next` 维持。要访问第 $i$ 个元素，必须从头指针出发走 $i-1$ 步，这正是链表不能随机访问的原因。访问第 1 个和第 $10^6$ 个元素的代价相差百万倍。

## 单链表的插入与删除

在第 $i$ 个位置插入，先找到第 $i-1$ 个结点 $p$，再执行两步：

```c
s->next = p->next;   /* 先接后继，顺序不能反 */
p->next = s;
```

若先写 `p->next = s`，`p` 原来的后继就丢失了，`s->next` 无处可取。删除第 $i$ 个结点同样先找前驱 $p$：

```c
q = p->next;
p->next = q->next;
free(q);
```

追踪一次：表为 `head -> 10 -> 20 -> 30`，删除第 2 个元素。`p` 停在 10，`q = p->next` 指向 20，`p->next = q->next` 让 10 直接指向 30，`free(q)` 释放 20，表变成 `head -> 10 -> 30`。三次指针赋值，与表长无关。

| 操作 | 顺序表 | 单链表 |
| --- | --- | --- |
| 按位序取值 | $O(1)$ | $O(n)$ |
| 按值查找 | $O(n)$ | $O(n)$ |
| 已知前驱插入 | $O(n)$（要移动） | $O(1)$ |
| 删除已知结点 | $O(n)$ | $O(1)$（需前驱） |
| 存储密度 | 1 | 小于 1（含指针域） |
| 空间需求 | 连续大块 | 离散小块，可动态增长 |

> [!NOTE]
> 链表的「插入 $O(1)$」有个前提：已经拿到前驱指针。若只知道位序 $i$，找前驱本身要 $O(n)$，整体还是 $O(n)$。讨论复杂度时必须说清输入是什么。

## 双向链表与循环链表

双向链表每个结点多一个 `prior` 指针，可以反向遍历，也能在已知结点 $p$ 时直接 $O(1)$ 删除，不必再找前驱：

```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode;

/* 在 p 之后插入 s */
s->next = p->next;
s->prior = p;
p->next->prior = s;
p->next = s;
```

四步赋值的顺序有讲究：前两步先让 $s$ 接上后继和前驱，第三步改后继的 `prior`，最后才改 `p->next`，否则 `p->next` 已被覆盖，找不到原来的后继。

循环链表把尾结点的 `next` 指回头结点，形成环。好处是从任一结点出发都能遍历全表，尾结点可以由 `rear->next` 在 $O(1)$ 内找到，适合实现队列。判空条件也随之变化：带头结点的循环链表空表满足 `L->next == L`。

三种形态的取舍是：单链表省空间、够用即可；双向链表用一倍指针换双向遍历与 $O(1)$ 删除；循环链表消除边界判断，适合环形调度。

## 三个常见误解

> [!MYTH] 链表插入删除一定是 $O(1)$。
> 只有在已经持有前驱（或该结点本身，且是双向链表）时才是 $O(1)$。按位序操作要先走 $O(n)$ 步定位。

> [!MYTH] 头指针就是头结点。
> 头指针是必须存在的指针变量，指向链表起点；头结点是可选的、不存数据的结点。带头结点时头指针指向头结点，而不是首元结点。

> [!MYTH] 链表比顺序表省空间。
> 链表每个结点多一个或两个指针域，存储密度小于 1。它的优势是按需分配、不要求连续空间，不是空间更少。

## 练习

> [!PRACTICE] 1 · 写指针
> 在单链表结点 $p$ 之后插入 $s$，写出两条赋值并说明顺序理由。
>
> > [!ANSWER] 看答案
> > `s->next = p->next; p->next = s;`。必须先让 $s$ 接住原后继，否则第二步覆盖后 $s$ 无处可指。

> [!PRACTICE] 2 · 数移动
> 表长 $n=100$，删除第 50 个结点，顺序表与单链表各需多少次元素移动或指针赋值？
>
> > [!ANSWER] 看答案
> > 顺序表移动 $100-50=50$ 个元素；单链表定位走 49 步，删除本身 3 次指针操作。

> [!PRACTICE] 3 · 判空
> 带头结点的循环双链表，判空条件怎么写？
>
> > [!ANSWER] 看答案
> > `L->next == L`（等价地 `L->prior == L`），头结点的两个指针都指向自己。

## 严格表述

链表是线性表的链式存储表示：结点由数据域与指针域组成，逻辑上相邻的元素在物理上不必相邻，其后继位置由指针显式记录。单链表按位序访问第 $i$ 个元素需沿指针走 $i-1$ 步，时间为 $O(n)$；在已知前驱结点 $p$ 的条件下，插入与删除均为 $O(1)$，且只需常数次指针赋值。头结点是不存储数据的附加结点，其存在使首元位置的插入删除无需特判头指针。双向链表以额外的 `prior` 域换取反向遍历与已知结点的 $O(1)$ 删除；循环链表令尾结点指向头结点，使任意结点可达全表。链表的存储密度小于 1，但不要求连续存储空间，容量可按需增长。
