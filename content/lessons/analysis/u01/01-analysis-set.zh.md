## 本讲目标

学完这一讲，你能用集合的语言准确说出“哪些对象属于某个范围”，并独立完成子集判断、集合运算和 De Morgan 公式的证明。

这一讲只做三件事：把集合说清楚、把运算写清楚、把“证明两个集合相等”变成一套固定动作。

## 三行回顾

- 数学分析研究的是函数，而函数的定义域和值域都是集合。
- 所以第一步不是极限，而是把“集合”和“属于”这两个词说清楚。
- 后面的极限、连续、开集，都会用同一套语言重写。

## 集合与元素

**集合**是具有某种确定性质的对象汇成的整体，这些对象叫**元素**。若 x 是 S 的元素，记作 x ∈ S；否则记作 x ∉ S。

> [!MYTH] 确定性
> 任一对象是否属于这个集合，必须能判断。不能出现“可能属于”的模糊地带。

> [!MYTH] 互异性
> 同一个元素重复写，不会产生新元素。{a, a, b} 就是 {a, b}。

> [!MYTH] 无序性
> 元素没有先后。{a, b} 与 {b, a} 是同一个集合。

常用数集：正整数集 N*、整数集 Z、有理数集 Q、实数集 R。集合里的对象不必是数，也可以是颜色、字母、函数，甚至别的集合。

## 两种表示法

| 方法 | 写法 | 例子 | 注意 |
| --- | --- | --- | --- |
| 列举法 | A = {a, b, c} | {红, 绿, 蓝} | 元素可数，或规律足够明确 |
| 描述法 | S = { x \| x 满足 P } | { x ∈ R \| x > 0 } | 竖线左边写代表元素，右边写条件 |

无限但有规律的集合，列举法也可以写开头和通项：N* = {1, 2, 3, …}。

有理数集写成 Q = { p/q | p, q ∈ Z, q ≠ 0 } 时，要先说明 p、q 取自哪里，否则条件不完整。竖线两边也不能反：左边是“谁”，右边是“它要满足什么”。

## 子集、相等与计数

设 S、T 是两个集合。若 S 的每个元素都属于 T，即对任意 x，x ∈ S ⇒ x ∈ T，则称 S 是 T 的**子集**，记作 S ⊆ T。

| 概念 | 条件 | 记号 |
| --- | --- | --- |
| 子集 | 每个 x ∈ S 都有 x ∈ T | S ⊆ T |
| 真子集 | S ⊆ T 且 S ≠ T | S ⊂ T |
| 相等 | S ⊆ T 且 T ⊆ S | S = T |

**空集 ∅** 不含任何元素，但它是任何集合的子集；任何集合也是自身的子集。

> [!NOTE]
> S = T ⇔ S ⊆ T 且 T ⊆ S

这不是一句口号，而是证明集合相等的标准动作——两个方向各证一次。计数：含 n 个元素的集合有 **2ⁿ** 个子集，**2ⁿ − 1** 个真子集。理由：每个元素都有“选”或“不选”两种状态；去掉“全选”得到的自身，剩下 2ⁿ − 1 个真子集。

## 四种基本运算

| 运算 | 记号 | 元素条件 | 例（A={a,b,c}，B={b,c,d,e}） |
| --- | --- | --- | --- |
| 并 | A ∪ B | x ∈ A 或 x ∈ B | {a, b, c, d, e} |
| 交 | A ∩ B | x ∈ A 且 x ∈ B | {b, c} |
| 差 | A \ B | x ∈ A 且 x ∉ B | {a} |
| 补 | Aᶜ | x ∈ X 且 x ∉ A | 需先指定全集 X |

> [!NOTE]
> A \ B = { x | x ∈ A 且 x ∉ B }　　Aᶜ = { x ∈ X | x ∉ A }

注意：差和补不是一回事。A \ B 不需要全集；Aᶜ 必须先在某个全集 X 里说话。离开全集谈补集，是没有定义的。

## 运算律与 De Morgan

| 运算律 | 并 | 交 |
| --- | --- | --- |
| 交换 | A ∪ B = B ∪ A | A ∩ B = B ∩ A |
| 结合 | A ∪ (B ∪ D) = (A ∪ B) ∪ D | A ∩ (B ∩ D) = (A ∩ B) ∩ D |
| 分配 | A ∪ (B ∩ D) = (A ∪ B) ∩ (A ∪ D) | A ∩ (B ∪ D) = (A ∩ B) ∪ (A ∩ D) |

> [!NOTE]
> (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ　　(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ

**De Morgan 对偶律**不要背，做翻译。以第二个为例：x ∈ (A ∩ B)ᶜ ⇔ x ∉ A ∩ B ⇔ 并非“x ∈ A 且 x ∈ B” ⇔ x ∉ A 或 x ∉ B ⇔ x ∈ Aᶜ 或 x ∈ Bᶜ ⇔ x ∈ Aᶜ ∪ Bᶜ。每一步都是把“属于/不属于”翻译成逻辑连接词，最后再翻译回集合。两个方向都走一遍，等式就成立。

## Descartes 积

**有序对** (x, y) 讲究次序：x 来自第一个集合，y 来自第二个集合。

> [!NOTE]
> A × B = { (x, y) | x ∈ A 且 y ∈ B }

| 工艺 \ 颜色 | 红 | 绿 | 蓝 |
| --- | --- | --- | --- |
| 抽纱 | (红, 抽纱) | (绿, 抽纱) | (蓝, 抽纱) |
| 提花 | (红, 提花) | (绿, 提花) | (蓝, 提花) |
| 印染 | (红, 印染) | (绿, 印染) | (蓝, 印染) |
| 刺绣 | (红, 刺绣) | (绿, 刺绣) | (蓝, 刺绣) |

3 种颜色 × 4 种工艺 = 12 种窗帘品种。一般地，若 A 有 m 个元素、B 有 n 个元素，则 A × B 有 m × n 个元素。

R × R 记作 R²，就是平面直角坐标系；R × R × R 记作 R³，是空间直角坐标系。注意 A × B 与 B × A 一般不同，因为有序对的次序变了。

## 四个常见误解

> [!MYTH] 空集没有用。
> 空集是任何集合的子集，也是集合运算的边界。没有它，交集可能“无结果”，子集计数也会少一项。

> [!MYTH] {a, b} 和 {b, a} 是两个集合。
> 集合无序。只有有序对 (a, b) 才讲次序；{a, b} = {b, a}。

> [!MYTH] a 和 {a} 是一回事。
> a 是元素，{a} 是集合。a ∈ {a} 成立；a ⊆ {a} 通常不成立，因为左边不是集合。

> [!MYTH] A \ B 等于 A ∩ Bᶜ。
> 只有在同一个全集 X 下、且 A、B 都是 X 的子集时才成立。A \ B 本身不需要全集。

## 练习

> [!PRACTICE] 1 · 判断
> ∅ ⊆ {1, 2}？{1} ∈ {1, 2}？{1} ⊆ {1, 2}？
>
> > [!ANSWER] 看答案
> > 是；否，{1} 是集合不是元素；是。

> [!PRACTICE] 2 · 列举
> 写出 {a, b, c} 的全部子集，并数一数。
>
> > [!ANSWER] 看答案
> > ∅、{a}、{b}、{c}、{a,b}、{a,c}、{b,c}、{a,b,c}，共 8 个。

> [!PRACTICE] 3 · 证明
> 证明 (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ。
>
> > [!ANSWER] 看答案
> > 取任意 x，把 x ∈ (A ∩ B)ᶜ 逐字翻译成“x ∉ A 或 x ∉ B”，再翻译成 x ∈ Aᶜ ∪ Bᶜ；反向再走一遍。

> [!PRACTICE] 4 · 计算
> A = {1, 2}，B = {x, y}，求 A × B 与 B × A，并比较。
>
> > [!ANSWER] 看答案
> > A × B = {(1,x), (1,y), (2,x), (2,y)}；B × A = {(x,1), (x,2), (y,1), (y,2)}。两者一般不相等。

> [!PRACTICE] 5 · 综合
> 全集 X = {1,2,3,4,5}，A = {1,2}，B = {2,3}，求 A \ B、Aᶜ、A ∪ B、A ∩ B。
>
> > [!ANSWER] 看答案
> > A \ B = {1}；Aᶜ = {3,4,5}；A ∪ B = {1,2,3}；A ∩ B = {2}。

> [!FORMAL] 严格表述
> 集合相等的证明模板：要证 S = T，先证 S ⊆ T（任取 x ∈ S，推出 x ∈ T），再证 T ⊆ S。幂集基数可用归纳法：n = 0 时只有 ∅；加入第 n+1 个元素 a 后，每个子集都有“不含 a”与“含 a”两种版本，数量翻倍，故为 2ⁿ。
